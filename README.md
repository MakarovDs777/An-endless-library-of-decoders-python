# An-endless-library-of-decoders-python

1) Перебирает массивы, сгенерированные из последовательных сидов (starting_seed, rainbowRow),
2) Для каждого массива пытается применить ту же логику разделителя (sdf = max(arr) - 10),
3) Собирает символы по индексам и печатает получившийся текст (или сообщение об ошибке).
